# 《节拍幸存者》立项方案

> 立项日期：2026-10-05。这是最初的方案草稿，正式设计以 `docs/设计.md` 为准。

## 一句话
类《吸血鬼幸存者》的割草游戏，但每件武器是一件乐器，所有攻击都卡在节拍上发射。一局约 8 分钟，打完就是一首由你的 build 决定的电子乐。

## 核心循环
走位躲怪 → 武器按节拍自动攻击 → 吃经验升级 → 三选一（选的是"加一轨乐器"或强化已有乐器）→ 越强音乐越满 → Boss 在 drop 处出场 → 结算。

## 关键设计点
- **武器即乐器**：底鼓 = 冲击波，踩镲 = 连射，琶音 = 追踪弹，贝斯 = 激光扫过，Pad = 护盾/光环……每种乐器的攻击形态要和它的声音性格一致。
- **量化**：所有攻击、敌人刷新、特效都对齐到拍子/小节（16 分音符网格），保证"手感 = 节奏感"。
- **永远好听**：音高都从同一调式里取，和弦进行由游戏控制，玩家怎么选都不会难听。
- **音乐即进度**：开局只有一个底鼓，升级逐层叠加；8 分钟里有 intro → build-up → drop → breakdown → 终极 drop 的曲式，Boss 和刷怪潮跟着曲式走。
- **局外成长**：解锁新乐器、新角色（不同曲风：synthwave / drum&bass / lo-fi / chiptune……），存 localStorage。

## 视觉方向
霓虹、辉光、加法混合；画面随低频脉动，底鼓时屏幕轻微震动/缩放，敌人死亡的粒子也卡拍。参考 Rez、Tetris Effect 的联觉感。

## 参考
Vampire Survivors、Rez、Tetris Effect、Thumper、Brotato

## 技术约束
- 纯前端，无后端；桌面浏览器优先（Edge / Chrome），键盘操作（WASD / 方向键），能顺手支持触屏更好
- 声音用 WebAudio 实时合成（不依赖采样文件，或只用很少），用 AudioContext 时间做调度，画面跟音频时钟对齐而不是反过来
- 最好双击 `index.html` 就能玩；需要构建就用 Vite，产物是纯静态文件
- 界面文案用简体中文
