# 《节拍幸存者》设计文档

> v1.0 · 2026-10-05 · 上游：`docs/方案.md`。正式设计以本文为准，开发中的修订直接写回本文。
> 本版已按实际实现更新；代码结构、调试方法、调参记录见 `docs/开发记录.md`。

## 0. 设计支柱

1. **你的 build 就是你的歌**：每件武器是一条音轨。开局只有起始乐器，选什么乐器、升到几级、带什么效果器，都直接听得见。一局结束，你拿到的是一首只属于这局的电子乐（还能在唱片架重放、导出 WAV）。
2. **一切落拍**：攻击、刷怪、敌人死亡爆炸、拾取音、钟琴弹跳、Boss 招式全部量化到 16 / 32 分音符网格。画面上的一切都在“演奏”。
3. **怎么选都好听**：音高只从当前和弦音和本调五声音阶里取，和弦进行由游戏控制，混音自动处理。玩家不需要懂音乐。
4. **曲式就是关卡**：前奏 → 铺垫 → 爆发（Drop）→ 回落 → 终极爆发 → 尾声，刷怪潮和 Boss 跟着曲式走。玩家能“听”出下一波什么时候来。
5. **联觉霓虹**：画面是音乐的可视化。底鼓让网格发光、屏幕涟漪；音高决定颜色；Drop 那一下全屏炸开。
6. **8 分钟一局**：随开随玩，打完一局正好一首歌。

## 1. 核心循环

### 1.1 操作

| 操作 | 键位 | 说明 |
|------|------|------|
| 移动 | WASD / 方向键 / 手柄左摇杆 | 自由移动，不量化（手感优先） |
| 冲刺 | 空格 / Shift / J / 手柄 A | 踩在拍点上 = **完美冲刺**（见 1.3） |
| 选择升级 | ←→ / A D 移动高亮（高亮即**试听**），空格 / 回车确认，1–4 直接选，鼠标也可 | 见 1.4 |
| 刷新 / 放逐 | R / X | 次数来自工作室强化 |
| 暂停 | Esc / P / 手柄 Start | 暂停时音频整体挂起；切到后台自动暂停 |

武器全部自动攻击，玩家专心走位和踩拍。

### 1.2 三层循环

- **30 秒循环**：走位躲怪 → 乐器按节拍自动攻击 → 敌人在下一个 16 分音符上爆炸 → 吸经验 → 升级三选一（音乐循环 + 试听）→ 新乐器在下一拍入场。
- **一局循环（约 8 分钟）**：曲式推进 → 铺垫段敌人合围、倒数 3·2·1、最后一拍静音 → Drop 瞬间全屏冲击清场 + Boss 进场 → 回落段喘息、打精英拿宝箱 → 终极 Drop 打指挥家 → 尾声结算。
- **局外循环**：结算得到唱片和音符 ♪ → 工作室买永久强化、解锁角色和乐器 → 换 build / 换曲风再来。

### 1.3 踩拍冲刺与律动值（Groove）

不踩拍也能完整通关；踩拍是给想玩出节奏感的人的技巧上限。

- 冲刺：0.135 秒位移约 170 单位，冲刺过程无敌。2 格充能（碎拍 3 格），每格 2 拍回复。
- **完美冲刺**：按键时刻离最近的四分音符拍点 ≤ ±70ms（脉冲 +15ms，节拍器每级 +12ms）。完美冲刺**不消耗充能**，落点放一圈冲击波（伤害随等级成长），并叠加“完美连击”。所以踩准了可以每拍一冲。Good（±140ms）只给少量律动。
- 判定用“听到的时间”：按键事件时间戳换算到音频听感时间再比对；设置里有手动延迟补偿和“跟拍按 8 次”的自动校准。
- **律动值 0–100**：完美冲刺 +15，Good +5，每次击杀 +0.12；每秒衰减 3（脉冲 −30%）；被打 −25。
  - ≥30 律动 I：伤害 ×1.10，背景加入沙锤
  - ≥60 律动 II：伤害 ×1.20，拾取范围 +30%，背景加入和弦 Stab，升级时**四选一**
  - ≥90 律动 III：伤害 ×1.35，每拍回复 0.25 生命，背景加入反拍踩镲，玩家拖出彩虹尾迹
- HUD 上是一块 VU 表，指针随律动值摆动。

### 1.4 升级：循环试听（hold 模式）

升级时**游戏模拟冻结，音乐不停**——DJ 式“循环保持”：

- 音乐循环播放当前这一小节（和弦不变、曲式位置冻结），主总线压一个带共振的低通（约 900Hz），像把音乐“含在嘴里”。
- **高亮哪张卡，就把那张卡的效果加进循环里试听**：新乐器会直接响起来；效果器会真的改变混音（失真变脏、延迟回声变多……）。
- 选定后：在下一个 16 分音符恢复，低通在约一拍内打开，模拟在恢复那一刻同步解冻。
- 恢复时从循环里的当前位置接着走，乐句不断；段落边界都在小节线上，循环多几拍少几拍不影响曲式。
- 连续升级就连续选；宝箱开箱也走同样的 hold，开出的东西会直接加进循环里。

### 1.5 量化的反馈

- **死亡量化**：敌人吃到致命伤立刻失去碰撞、闪白，在**下一个 16 分音符**上爆炸，同时播放一个取自本调五声音阶的玻璃音（每个 16 分最多 2 个）。
- **拾取音阶**：经验宝石连续拾取时，提示音沿五声音阶一级级往上爬（量化到 16 分），停顿 1 秒后从头开始。
- **受击**：主总线瞬间压低通并降音量，配一个下滑的“故障”音，画面红色描边 + 色差 + 震屏。
- **群体脉动**：敌人移动速度随拍子起伏（拍点上冲一下再回落，平均速度不变），体型随底鼓轻微缩放。
- **敌人也落拍**：节拍器敌人第 3 拍亮起预警、第 4 拍开火（木鱼声就在那一拍）；回授敌人点燃引信后在下一拍爆炸。

## 2. 乐器 = 武器（10 件）

一件乐器 = 一条音轨 = 一把武器。最多 6 条乐器轨 + 4 个效果器。满级 6 级。

- 节奏型随**等级、段落、曲风**变化：铺垫段加密成滚奏，回落段稀疏，尾声逐轨退出；同一件乐器在 DnB 里是碎拍、在 Lo-fi 里是摇摆的 boom-bap。
- 每次命中的伤害做两种归一化：节奏型越密每下越轻（指数 0.7），BPM 越快每下越轻（×128/BPM）。DPS 主要由等级决定。
- 开局卡池有 6 件（底鼓、军鼓、踩镲、贝斯、铺底、琶音），其余 4 件靠成就或音符解锁。

| 乐器 | 攻击形态 | 声音性格 | 6 级 | Remix（满级 + 对应效果器） |
|------|---------|---------|------|-------------------------|
| 底鼓 Kick | 以你为中心的冲击波，范围伤害 + 击退；回落段只打第 1 拍（一次超大冲击） | 正弦扫频鼓 + 起音咔哒，驱动侧链 | 重拍二次扩散 + 减速 | **硬核底鼓**（失真）：失真长尾，冲击环留下灼烧圈 |
| 军鼓 Snare | 2、4 拍朝移动方向打出扇形碎片，穿透 | 噪声 + 音体，带混响 | 重音时向身后也打一扇 | **门限军鼓**（混响）：碎片停下时炸开一圈冲击 |
| 踩镲 Hi-hat | 朝最近敌人连射光弹；开镲弹大且穿透 | 808 式金属方波簇 | 开镲弹命中分裂 4 片 | **幽灵镲**（延迟）：每发都带两发延迟回声弹 |
| 贝斯 Bass | 从你身上射出的穿透激光；长音扫过一段弧 | 锯齿 + 次低音，被侧链泵动；DnB 是 Reese | 高八度反方向第二道 | **摇摆贝斯**（侧链）：激光随 LFO 摆动并把敌人吸向光束 |
| 铺底 Pad | 周身光环每 8 分音符跳一次伤害；换和弦时脉冲，每 2 小节给一层护盾 | 失谐超级锯齿，慢起慢收 | 脉冲翻倍并回血 | **天穹**（压缩器）：光环 +40%，护盾可叠 2 层 |
| 琶音 Arp | 每个音一颗追踪音符，**颜色由音高决定**，一半优先追 Boss | 失谐锯齿拨弦 + 附点八分延迟 | 命中后弹射，弹射音高上行 | **超锯齿琶音**（合唱）：每个音分裂成 3 颗 |
| 和弦 Stab | 每个和弦音一发重型星形弹，环形散开 | Rave stab | 射程尽头爆炸 | **锐舞和弦**（激励器）：沿途留下爆炸火花 |
| 钟琴 Bell | 链式闪电在敌人之间弹跳，每跳一次音高上行（32 分网格） | FM 钟声 | 弹跳 8 次 | **风铃**（滤波 LFO）：每次闪电分叉 |
| 嗵鼓 Toms | 乐句末的过门：光柱从天而降轰击敌群 | 下行音高的嗵鼓 | 每小节过门，光柱成对 | **定音鼓**（节拍器）：光柱巨大并眩晕一拍 |
| 主旋律 Lead | 旋律音符沿正弦轨迹飞行，穿透一切，长音更大 | 锯齿 / 方波主音，滑音 + 颤音 | 闪光拖尾持续伤害 | **独奏**（母带）：每个音符同时射向四个方向 |

每件乐器 1–6 级的具体效果见游戏内卡片（数据在 `js/game/instruments.js`）。

## 3. 效果器 = 被动（10 个）

效果器作用于整首歌的混音，所以**被动也是听得见的**。每个满级 5 级，最多装 4 个。

| 效果器 | 战斗效果（每级） | 听觉变化 |
|--------|----------------|---------|
| 失真 Overdrive | 伤害 +12% | 并联失真加大，声音变脏变暖 |
| 混响 Reverb | 攻击范围 / 弹体大小 +12% | 混响返回量增加 |
| 延迟 Delay | 20% 概率回声攻击（附点八分后再来一次，50% 伤害） | 乒乓延迟反馈增加，回声与回声攻击同时出现 |
| 合唱 Chorus | 1 / 3 / 5 级弹体 +1；2 / 4 级伤害 +8% | 两路调制延迟，声音变宽 |
| 压缩器 Compressor | 最大生命 +20，受伤 −6% | 胶水压缩更狠 |
| 侧链 Sidechain | 拾取范围 +25%；每次底鼓把附近经验吸过来 | 泵感加深 |
| 节拍器 Metronome | 完美判定 +12ms，冲刺回复 −10% 时间 | 每拍多一个嘀嗒 |
| 滤波 LFO | 移速 +8% | 低通滤波随两小节一周期扫动 |
| 激励器 Exciter | 暴击率 +7%（暴击 2 倍） | 高频搁架提升，更亮 |
| 母带 Mastering | 经验 +10%，每小节回复 0.3 生命 | 整体更响 |

升级卡池：未满级的已有乐器（权重 1.6）、未拥有的乐器（前 6 级权重 3，之后 1.3）、效果器（0.9 / 1.1）。前 5 级保证至少一张新乐器卡。

## 4. 曲式、刷怪与 Boss

### 4.1 曲式表（按 128 BPM；其它曲风按 BPM 缩放到相近时长，取 4 的倍数）

| 段落 | 小节 | 时间 | 音乐 | 刷怪 / 事件 |
|------|------|------|------|------------|
| 前奏 | 1–16 | 0:00–0:30 | 起始乐器 + 低通氛围 pad 慢慢打开 | 稀疏小怪 |
| 律动 A | 17–40 | 0:30–1:15 | 加入拍手、和弦 | 稳步增加，0:50 起快怪 |
| 铺垫 1 | 41–48 | 1:15–1:30 | 军鼓滚奏、上升音、滤波打开；最后一拍全体静音 | 最后 4 小节每小节一圈合围；倒数 3·2·1 |
| 爆发 1 | 49–80 | 1:30–2:30 | 全开，镲片 + 低频冲击 | 全屏冲击清场；**Boss 低音炮** |
| 回落 1 | 81–96 | 2:30–3:00 | 底鼓只打第 1 拍，梦幻七和弦，末尾小上升音 | 敌人少而慢，精英掉宝箱 |
| 律动 B | 97–128 | 3:00–4:00 | 换和弦进行 | 毛刺流、低频方阵，3:00 起节拍器敌人 |
| 铺垫 2 | 129–136 | 4:00–4:15 | 同上 | 双层合围 |
| 爆发 2 | 137–168 | 4:15–5:15 | 全开 | **Boss 频谱**；4:00 起回授敌人 |
| 回落 2 | 169–184 | 5:15–5:45 | | 精英 ×2 |
| 铺垫 3 | 185–192 | 5:45–6:00 | | 三层合围 |
| 终极爆发 | 193–240 | 6:00–7:30 | **升调 +2 半音** | **Boss 指挥家**；没打死就循环最后 8 小节“加时”，刷怪逐次 +30% |
| 尾声 | 241–256 | 7:30–8:00 | 乐器逐轨退出，落到主和弦 | 击败指挥家后从下一个 4 小节乐句开始；残余敌人按拍溶解，经验自动吸附 |

- Boss 1 / 2 没在其 Drop 段内打死，会在回落段开头退场（不掉宝箱）。Boss 在场时普通刷怪 ×0.65。
- Drop 第一拍：白闪（可减弱）、色差、镜头冲击、低频轰鸣、免费的全屏冲击波。

### 4.2 刷怪导演

- 每个段落有“每小节刷怪预算”，按拍点分批刷在屏幕外一圈（偏向玩家前进方向）。
- 阵型：合围圈（铺垫段）、毛刺流（一列快怪直线横穿）、低频方阵、精英（回落段）。
- 同屏上限 620，太远的敌人回收到前方。
- 敌人血量随时间成长：`倍率 = 1 + 0.30·分钟 + 0.035·分钟²`；接触伤害 `× (1 + 0.07·分钟)`。

### 4.3 敌人

| 敌人 | 形状 | 生命 | 速度 | 接触伤害 | 经验 | 出现 |
|------|------|------|------|---------|------|------|
| 杂音 | 红三角 | 10 | 88 | 8 | 1 | 开局 |
| 毛刺 | 品红细菱形 | 6 | 168 | 6 | 1 | 0:50 |
| 低频块 | 橙色大六边形 | 70 | 56 | 12 | 5 | 2:00，抗击退 |
| 节拍器 | 黄方块 | 28 | 80，保持距离 | 6 | 3 | 3:00，第 4 拍射弹 |
| 回授 | 橙色圆环 | 20 | 120 | 6 | 3 | 4:00，靠近后下一拍自爆 |
| 精英 | 金色描边放大版 | ×16 | ×0.85 | ×1.5 | 25 | 回落段，掉宝箱 + 回血 |

### 4.4 Boss（所有招式提前一拍预警，在拍点上生效，声音也在那一拍）

- **低音炮**（生命 2500）：每小节第 1 拍放一圈有缺口的冲击环（从缺口走或冲刺穿过），第 3 拍召唤一圈杂音；半血后每 2 拍一环、缺口变窄。
- **频谱**（生命 8000）：每 2 拍预警 2 道激光线（半血后 3 道），下一拍落下；每个 4 小节乐句的最后一小节放 16 分音符螺旋弹。
- **指挥家**（生命 27000）：三乐章（66% / 33% 切换，切换时全屏闪光）。一乐章冲击环 + 激光；二乐章双螺旋弹幕；三乐章“全奏”：环 + 激光 + 弹幕 + 毛刺流。被击败瞬间进入谢幕。
- 击败低音炮 / 频谱掉大宝箱和一堆经验。

## 5. 调式与和弦：保证怎么选都好听

- 每个曲风一个调，终极爆发升 2 个半音。和弦一小节一换（铺垫段两小节一换），按段落从该曲风的进行库里取。例如 House（A 小调）：主进行 Am–F–C–G，律动 B Am–Em–F–G，铺垫 F–F–G–G，回落 Fmaj7–Em7–Dm7–Cmaj7，尾声 F–G–Am。
- 取音规则：
  - 贝斯：当前和弦根音（高八度 / 五度交替）
  - Pad / Stab：三和弦或七和弦，按最近声部进行选转位
  - 琶音：只用当前和弦音，上下行，跨 1–2 个八度
  - 钟琴 / 主旋律 / 击杀音 / 拾取音：本调五声音阶，强拍落和弦音
- 自动混音：底鼓不进侧链、旋律与 Pad 被底鼓侧链；踩镲高通；拨弦、Pad、钟琴走延迟和混响；总线 LFO 滤波 → hold 低通 → 并联失真 → 激励 → 胶水压缩 → 限幅。离线实测满编 RMS 约 −10 dBFS、峰值约 −1.5 dBFS、零削波。

## 6. 数值框架

| 玩家属性 | 初始 |
|---------|------|
| 生命 | 100（方波 80） |
| 移速 | 215 单位/秒（画面竖向 1000 单位） |
| 拾取范围 | 95 |
| 受击无敌 | 0.8 秒 |
| 冲刺 | 2 格充能，每格 2 拍回复 |

- 经验宝石：青（1）、绿（5+）、金（20+）、粉（50+，溢出合并）。升到 L+1 级需要 `10 + 6L + 0.55L²`。
- 回血：敌人 0.4% 掉回血（+20），0.15% 掉磁铁（全屏吸经验）；精英必掉宝箱 + 回血。
- 宝箱：有可进化的乐器就必出 Remix；否则精英宝箱 1 个（75%）或 3 个已有项升级，Boss 大宝箱 3 或 5 个。
- 模拟验证（自动驾驶，约六成完美冲刺）：一局 7:15–8:47 通关，约 30–35 级；Boss 击杀用时 低音炮 20–60 秒、频谱 25–60 秒、指挥家 50–130 秒；第二个 Drop 是主要难点。

## 7. 角色 = 曲风（5 个）

## 8. 局外成长

- **音符 ♪**：结算发放 `击杀/40 + Boss×30 + 通关 90 + 等级×2 + 完美冲刺×0.5`（+ 局内补给）。
- **工作室（永久强化，可全额退款重配）**：生命、力量、范围、移速、拾取、经验、护甲、冲刺、刷新次数、放逐次数、安可（阵亡复活一次）。
- **解锁**：4 个角色 + 4 件乐器（和弦 Stab、钟琴、嗵鼓、主旋律），各自对应一个成就，也可以直接花音符买。
- **成就**：12 个（首演、拆掉低音炮、频谱分析、谢幕、千人斩、降噪、踩点大师、满编乐队、混音师、入迷、神级现场、全曲风）。
- **唱片架**：每局 2 分钟以上留下一张唱片（播放的小节序列 + 编曲变化时间线），可在菜单里重放（带编曲视图和播放头），也能用离线渲染**导出 WAV**。曲名由主乐器和主效果器生成（如《回声星轨》《呼吸心跳》）。
- 评级：S（通关且分数 ≥ 13000）/ A / B / C / D。

## 9. 美术方向

- 近黑底色 + 纯加法混合的霓虹几何体，HDR + 6 级 Bloom + ACES 色调映射。
- 配色：玩家与武器偏冷（底鼓青白、踩镲金黄、琶音按音高变色、贝斯紫），敌人偏暖（红、橙、品红），经验宝石青 / 绿 / 金 / 粉。音高按五度圈映射到色环。
- 背景：无限霓虹网格，底鼓时整体亮一下并从玩家处扩散一圈亮环；冲击波在后处理里扭曲画面；视差尘埃；段落改变色调（回落偏紫、Drop 更亮、终极爆发偏红）。
- 玩家：发光菱形飞船，周围环形频谱（实时 AnalyserNode），身后冲刺充能点，护盾环，律动 III 彩虹尾迹。
- **玩家特效自动曝光**：每帧估算玩家特效的“亮度 × 面积”总量，超过预算就整体压暗（最低 20%），满屏弹幕时敌人和 Boss 招式依然清楚；另有“玩家特效强度”设置。
- HUD：曲式时间轴（段落色块、播放头、Boss 标记、“距 爆发 n 小节”）、调音台（每轨电平灯随攻击跳动、Remix 标记）、效果架、律动 VU 表、生命 / 等级 / 连击、时间 / 击杀 / 调性 / 当前和弦、经验条、Boss 血条。
- 结算：DAW 式编曲视图（按实际播放顺序的段落条 + 每条轨从第几小节入场、每次升级的亮度变化、Remix 星标）。
- 光敏安全：“减弱闪烁”（白闪降到 25%、色差降低）；屏幕震动可关。

## 10. 技术方案

- **不需要构建**：`index.html` + 经典 `<script>` 按依赖顺序加载（file:// 下 ES Module 会被拦截），零外部依赖，双击即玩（已用 Edge 以 file:// 实测）。
- **音频时钟驱动**：向前看调度（定时器 16ms + 每帧，提前 150ms）；`getOutputTimestamp()` 外推听感时间；事件在听感时间到达时处理，弹体做亚帧补偿。实测事件滞后平均约 2ms。掉队太多时静默跳过，不补发过期的音。
- **渲染**：WebGL2 单批次实例化 SDF（圆、环、三角、菱形、方块、六边形、胶囊、星、带缺口的弧、十字），RGBA16F 场景缓冲，CoD 式降 / 升采样 Bloom，合成里做涟漪、色差、暗角、颗粒、白闪、曲风调色 / 像素化 / 扫描线。实测满屏（1500+ 图元）每帧 CPU 约 1ms。
- **离线渲染**：同一套音频图可以建在 OfflineAudioContext 上，用于导出 WAV 和开发期的混音电平检查。
- **自测工具**：调试面板、自动驾驶、无声虚拟时钟的模拟模式（一局 10–20 秒跑完）、离线混音电平表。详见 `docs/开发记录.md`。
- 存档：localStorage 键 `beat-survivors-v1`（设置、音符、强化、解锁、成就、纪录、唱片）。
- 部署：Cloudflare Pages（beat.xiaoming6680.link，子域名根路径），连接 GitHub 仓库，推送 main 自动上线；构建时 `tools/dist.py` 把 `index.html`、`css/`、`js/` 复制到 `dist/` 作为产物。

## 12. 风险与对策

| 风险 | 对策 |
