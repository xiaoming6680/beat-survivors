# 开发记录

面向开发者：代码结构、怎么调试 / 自测、调参记录。玩法设计见 `设计.md`，玩家说明见根目录 `README.md`。

## 运行

- 玩家：直接双击 `index.html`（经典 `<script>`，不用构建，file:// 下可用）。
- 开发：`python tools/serve.py`，打开 <http://localhost:8917/>。这个服务器禁用缓存，改完代码刷新就生效（python 自带的 http.server 会被浏览器启发式缓存，改了 JS 刷新不一定生效）。

## 部署

- 仓库：<https://github.com/xiaoming6680/beat-survivors>（公开）
- Cloudflare Pages 项目 `beat-survivors`，连接 GitHub：**推送到 main 就自动构建上线**，其它分支生成预览地址。
  - 构建命令：`PYTHONUTF8=1 python3 tools/dist.py`，输出目录：`dist`，构建镜像 v3
  - `tools/dist.py` 只把运行时文件（`index.html`、`css/`、`js/`，约 300KB）复制到 `dist/`（已在 `.gitignore`），docs、tools 不会发上去
- 地址：<https://beat.xiaoming6680.link>（自定义域名，DNS 是 `beat` → `beat-survivors.pages.dev` 的代理 CNAME），备用 <https://beat-survivors.pages.dev>
- 游戏是纯静态文件、全部相对路径，放在子域名根路径即可；线上和本地双击是同一份代码，存档按域名存在 localStorage，线上和本地各自独立。

## 代码结构

加载顺序就是 `index.html` 里 `<script>` 的顺序，各模块是全局对象。

| 文件 | 内容 |
|------|------|
| `js/util.js` | `U`：数学、种子随机、颜色（sRGB→线性）、音高→颜色；`SpatialGrid`：以玩家为中心的计数排序网格 |
| `js/audio/harmony.js` | `Harmony`：和弦品质、音阶、五声音阶、声部进行 |
| `js/audio/engine.js` | `AE`：音频图（侧链、LFO 滤波、hold 低通、失真并联、激励、胶水压缩、限幅、混响、门限混响、乒乓延迟、合唱）；`AE.Clock` 听感时钟；效果器等级 → 混音参数 |
| `js/audio/synths.js` | `Synth`：所有音色（鼓、贝斯、拨弦、Pad、Lead、Stab、FM 钟、上升音、镲片、音效、UI） |
| `js/render/gl.js` | `R`：WebGL2 实例化 SDF 图元、HDR 场景缓冲、6 级 Bloom、合成（涟漪、色差、暗角、颗粒、白闪、ACES） |
| `js/game/styles.js` | `STYLES`：5 个曲风角色（BPM、调、和弦进行、音色预设、鼓型偏好、配色、被动） |
| `js/game/song.js` | `Song`：曲式表（按 BPM 缩放）、和弦查询、加时循环 / 尾声跳转 |
| `js/game/instruments.js` | `INST`：10 件乐器的节奏型、取音、发声、攻击 |
| `js/game/effects.js` | `FX`：10 个效果器；`Effects.compute` 汇总属性 |
| `js/audio/sequencer.js` | `Seq`：向前看调度、hold 循环 / 试听、伴奏层、唱片回放 |
| `js/audio/offline.js` | `Offline`：离线渲染（导出 WAV、混音电平检查） |
| `js/game/enemies.js` | `ENEMY` 5 种敌人；`BOSS` 3 个 Boss |
| `js/game/director.js` | `Director`：按曲式刷怪、合围、毛刺流、低频方阵、精英 |
| `js/game/world.js` | `W`：玩家、敌人、弹体、危险物、拾取、粒子、事件处理、量化死亡 |
| `js/game/upgrades.js` | `Upgrades`：三选一、宝箱、Remix |
| `js/game/meta.js` | `Meta`：存档、工作室、解锁、成就、唱片架 |
| `js/render/scene.js` | `Scene`：把世界画进渲染批次、相机、后处理参数 |
| `js/ui/ui.js` / `screens.js` | HUD；菜单与各界面 |
| `js/main.js` | `Game` 状态机与主循环、输入（键盘 / 手柄）、`Bot` 自动驾驶、`Sim` 模拟、`Debug` 面板 |

## 时间与同步（最重要的部分）

- **音频时钟是主时钟**。音序器每 16ms（定时器）和每帧都调用 `Seq.tick()`，把 `currentTime + 0.15s` 以内的 16 分音符全部调度：声音用 WebAudio 在精确时间发出，同时把 `{t, 乐器, 音符}` 推进事件队列。
- **听感时间** `AE.Clock.now()`：`getOutputTimestamp()` 外推得到“扬声器此刻正在发出的音频时间”，再减去用户的延迟校准。游戏只在 `听感时间 ≥ t` 时处理事件，所以攻击和声音同时出现；弹体按 `听感时间 − t` 补偿位移。实测处理滞后 1–7ms。
- **hold（升级时）**：`Seq.hold()` 后小节位置继续循环但曲式位置冻结；试听编曲 `Seq.S.preview`；`Seq.release()` 返回恢复生效的时间 `resumeT`，模拟在听感时间到达 `resumeT` 前保持冻结。
- **量化**：敌人死亡、拾取音、钟琴弹跳、Boss 招式都落在网格上（`Seq.nextGrid` / `nextGrid32` / 拍点 + 一拍预警）。
- **暂停**：`AudioContext.suspend()`，时钟随之冻结。
- **rAF 停摆兜底**：定时器发现 rAF 超过 200ms 没来时自己驱动画面（真实浏览器切后台时游戏会自动暂停，这个兜底主要是给嵌入式 / 隐藏的 WebView）。

## 调试与自测

URL 参数（可组合）：

| 参数 | 作用 |
|------|------|
| `?debug` | 左下角调试面板：FPS、实体数、音频延迟、事件处理滞后、冲刺偏差；快捷键 L 升级、K 清屏、N 下一段、G 律动、I 无敌、H 回血、C 宝箱 |
| `?play=house` | 点开始后直接进这个角色的一局 |
| `?bot` | 自动驾驶（看演出 / 测帧率） |
| `?god` | 无敌 |
| `?lv=20` | 开局直接升到 20 级（自动选卡） |
| `?bar=44` | 从第 44 小节开始（跳到 Drop 前） |
| `?unlock` | 解锁全部角色和乐器（不写存档） |
| `?sim&speed=400&batch=house,chip,...` | 模拟模式：无声虚拟时钟 + 自动驾驶，一局 10–20 秒跑完，结果在 `window.__simAll` 和页面上 |
| `?skill=1.5` | 自动驾驶的踩拍误差倍数（越大越不准） |
| `?diff=1.2` | 难度倍率（敌人血量、刷怪量） |

控制台里：`await Offline.mixTest('house')` 渲染各乐器独奏和满编，返回峰值 / RMS / 低频 / 高频（dBFS）。

端到端：`python tools/e2e.py menu|play:...|chest|victory|remix:...|load:...`（需要 `pip install playwright`，用本机 Edge）。它以 file:// 打开游戏，等同玩家双击 `index.html`，输出帧率 / CPU / 报错，截图存到系统临时目录 `beat-survivors-shots/`。用法写在脚本开头。

## 调参记录

### 模拟（10 局 / 5 曲风，自动驾驶约六成完美冲刺）

见下方“最新一轮”；历次调整：

1. 第 1 轮：机器人躲 Boss，全程满血、Boss 不死；等级 7 分钟满。→ 机器人改为贴近 Boss 输出、模拟人手踩拍误差；经验曲线 `6+4L+0.35L²` → `10+6L+0.55L²`；律动 III 回血减半；Pad 护盾改每 2 小节。
2. 漏了 BPM 归一化（DnB 174 BPM 攻击多 36%）→ 音序器统一乘 `128 / BPM`。
3. 经验溢出时并入“随机宝石”会把经验塞到远处 → 并入附近宝石。
4. Boss 血量：低音炮 3200→2500，频谱 11000→8000，指挥家 42000→27000；Boss 在场时刷怪 ×0.65；第二个 Drop 刷怪略降。
5. DnB 起始武器军鼓太弱 → 碎片 5→6、伤害 10→14。
6. 清缓存后重测 10 局：5 局通关，阵亡集中在第二个 Drop → 频谱激光 20→16、螺旋弹 10→8，敌人接触伤害成长 0.09→0.07/分钟，受击无敌 0.65→0.8 秒；脉冲（初始角色）加被动：完美判定 +15ms、律动衰减 −30%。
7. 加了伤害来源统计（模拟结果里的 `dmgBy` / `lastHurts`）：后期大头是低频块的接触伤害 → 低频块接触伤害 15→12；方波每局都轻松通关（指挥家 28 秒）→ 方波被动加“伤害 −15%”。Lo-fi（84 BPM + 伤害 −10% + 防御型起始乐器）两个 Boss 都打不死 → 去掉伤害惩罚，回血 1→1.5/小节。
9. 最后一轮 10 局（5 曲风各 2 局，Lo-fi 加强之前）：8 局通关，通关时长 7:02–9:19，等级 29–38；阵亡 1 局 DnB（6:43）、1 局 Lo-fi（加时 10:13）。
8. 满级画面过亮：贝斯激光合唱最多多一道（其余折算成伤害）、短激光一闪即收；主旋律音符改成“音符头”样式；嗵鼓光柱变细；加“玩家特效自动曝光”（按亮度×面积估算负载，超出预算整体压暗，实测前期 0.01–0.05、后期 0.1–0.5、10 件全 Remix 0.4–5）和“玩家特效强度”设置。

### 混音（离线渲染，Drop 段 4 小节，乐器 6 级独奏）

- 第 1 轮踩镲独奏 RMS 只有 −44 dB（高通太高、增益太小），钟琴 −32 dB → 踩镲 ×2.8 并放低高通，钟琴 ×1.9，Stab ×1.3，拨弦 ×1.25。
- 现在：满编 RMS 约 −10 dB，峰值约 −1.5 dB，零削波；底鼓 / 贝斯 −14~−18，铺底 −15~−23，踩镲 −30~−38。

### 画面

- 初版 Bloom 过曝（阈值 0.35、强度 0.9、白色内核亮度 3）→ 阈值 0.6、强度 0.5、内核 1.7；玩家频谱环减半变细；Boss 受击改为细描边闪烁。

### 体验修复（用户试玩反馈，2026-10-05）

- **不知道为什么掉血**：受击时头顶飘“−伤害 + 来源”、身边红色弧线和箭头指向来源、屏幕边缘只在那一侧泛红（合成着色器 `u_hurtDir`）、攻击者被红圈标出、0.07 秒顿帧、血条抖动 + 延迟消退的掉血痕迹、低血量随拍子泛红。根因之一是判定比画面宽：冲击环判定 `厚度 + 12` 而画面只有 `0.6 × 厚度`，激光判定 `宽/2 + 12` → 统一改成飞船核心半径 7、判定宽度等于画面宽度。模拟里加了 `dmgBy` / `lastHurts` 可以看每局伤害来源。
- **选卡和冲刺同键**：选卡不再响应空格 / Shift / J（按了会提示用回车或 1–4）；升级界面弹出后 0.45 秒内忽略输入，按住不放的重复按键也忽略；宝箱继续改成回车 / 点击；手柄选卡用左右 + A，只认界面弹出后重新按下的 A。
- **主角看不清**：飞船改成轮廓清晰的箭头形（白色机头 + 驾驶舱 + 尾焰）并放大约 20%；渲染器加了分段混合模式，在飞船身后先画一圈“压暗”底（`dst × (1 − src)`）再画飞船，满屏特效里也能一眼找到自己；加了细定位环。
- **校准时空格重置校准**：点“开始校准”后按钮仍带焦点，松开空格会再次触发按钮。现在开始校准时移除焦点，游戏中 / 选卡 / 校准时 keyup 的空格和回车都 `preventDefault`；校准改成播放 16 下木鱼嘀嗒（落在音序器拍子网格上），去掉前 2 下取中位数。
- 新增端到端场景：`tools/e2e.py hurt | levelkeys | calib`。

## 已知限制

- 内置预览面板隐藏时 rAF 不触发（测试环境特性），靠定时器兜底。
- 导出整张唱片 WAV 时需要几十秒离线渲染、约 170MB 内存。
