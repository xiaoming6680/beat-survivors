# 节拍幸存者 BEAT SURVIVORS

类《吸血鬼幸存者》的割草游戏，但每件武器都是一件乐器，所有攻击都卡在节拍上。
一局约 8 分钟，打完就是一首由你的 build 决定的电子乐。

## 怎么玩

**双击 `index.html`** 就能在 Edge / Chrome 里玩，不用安装任何东西。建议戴耳机。

| 操作 | 键位 |
|------|------|
| 移动 | WASD / 方向键 |
| 冲刺（无敌） | 空格 / Shift —— **在拍点上按 = 完美冲刺** |
| 选升级 | ←→ 选择（高亮的卡片会加入音乐试听），空格 / 回车确认，1–4 直接选 |
| 刷新 / 放逐 | R / X（工作室里解锁次数） |
| 暂停 | Esc / P |

也支持手柄（左摇杆移动、A 冲刺、Start 暂停）。

## 玩法要点

- **乐器 = 武器**：底鼓放冲击波、踩镲连射、琶音发追踪音符、贝斯射激光……一共 10 件乐器。
- **效果器 = 被动**：失真、混响、延迟、合唱……既改数值，也真的改整首歌的混音。
- **Remix 进化**：满级乐器 + 对应效果器，从精英 / Boss 宝箱里开出来。
- **律动值**：完美冲刺让它上涨，越高伤害越高、音乐层次越多；被打会掉。
- **曲式就是关卡**：铺垫段敌人合围，Drop 那一拍全屏清场、Boss 进场；回落段喘口气。击败终极 Drop 的指挥家就通关。
- **5 个角色 = 5 种曲风**：House、Chiptune、Synthwave、Drum & Bass、Lo-fi，各有自己的 BPM、调式和音色。
- **局外成长**：每局赚“音符 ♪”，在工作室买永久强化、解锁角色和乐器。
- **唱片架**：每局超过 2 分钟会留下一张唱片，可以重放这局的歌，也能导出 WAV。

## 设置里能调的

音量、闪光强度（减弱闪烁）、屏幕震动、画质、音频延迟补偿（蓝牙耳机觉得“踩不准”时用设置里的校准）。
